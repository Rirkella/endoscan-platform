# ADR 0005: Pre-approval metadata-only access

## Context

Reviewers need evidence of source relevance and obtainability before authorizing large downloads or scientific assembly.

## Decision

Before assembly approval, providers may retrieve only reviewed, bounded metadata, manifests, availability evidence, and explicitly bounded samples. Full assay tables, matrices, and bulk identity work remain behind later authorization.

## Consequences

Source feasibility is reviewable with limited network/cost exposure. Metadata can be insufficient; that becomes a gap rather than permission to download unbounded data.

## Status

Accepted.
