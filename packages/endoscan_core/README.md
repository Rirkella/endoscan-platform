# endoscan_core

The framework-free domain and scientific library for EndoScan. It owns dataset
contracts and transforms, feature schemas, training, evaluation, inference,
explanation, diagnostics, and registry primitives. FastAPI and durable workflows
consume these tested interfaces rather than reimplementing scientific logic.

See the root [Architecture](../../docs/ARCHITECTURE.md) and
[Contributing](../../docs/CONTRIBUTING.md) documents for package boundaries and
scientific change rules.
